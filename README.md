Что где лежит
Program.cs: SignalR, CORS, статика, маппинг хаба на /hubs/monitor и три POST-эндпоинта (/api/system-message, /api/room-notification, /api/private-message).
Hubs/MonitorHub.cs: подключение и отключение, общий чат, комнаты, приватные сообщения, «Печатает…» и стрим чисел.
Services/ConnectionTracker.cs: singleton со словарем подключений. Он шлет счётчик онлайн и список пользователей, а также системные, комнатные и приватные сообщения через IHubContext.
Models/Requests.cs: модели запросов.
wwwroot/index.html, app.js, style.css: страница и клиент на чистом JS.
Как проверить по заданиям
1. Общий чат. Две вкладки, пишешь в одной, видишь в обеих. Открытие и закрытие вкладок видно в ленте.
2. Комнаты. В двух вкладках войди в alpha, в третьей в beta. Сообщения идут только внутри своей комнаты и выделены зеленым.
3. Онлайн. Счётчик вверху страницы. Кнопка «Системное сообщение всем» шлет HTTP POST, а сообщение приходит всем через SignalR.
4. Переподключение. Войди в комнату, в DevTools поставь Network в Offline, потом обратно в Online. Статус пройдёт «Переподключение…», потом «Подключено», и клиент сам войдет в комнату заново.
5. Приватные сообщения. Свой ID показан вверху (его можно скопировать). Приватные сообщения фиолетовые с пометкой «Приватное». «Внешнее уведомление в комнату» берёт название из поля комнаты.
Доп. 1. Печатай в поле комнаты, и в соседней вкладке той же комнаты появится «Пользователь печатает…». Исчезает через 2 секунды.
Доп. 2. Таблица «Пользователи онлайн». Клик по строке подставляет ID в поле «Кому».
Доп. 3. «Старт» запускает числа каждые 500 мс, они идут в график и список. «Стоп» останавливает. При закрытии вкладки поток на сервере тоже останавливается.

Комментарии в коде только у кусков доп. заданий.
